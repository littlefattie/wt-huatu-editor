# wt-huatu Editor

This is the demo site for wt-huatu tool  ([https://github.com/littlefattie/wt-huatu](https://github.com/littlefattie/wt-huatu)). 

It provides some editor and previewer for the preliminary try and test of `wt-huatu` tool/language.

The **Second** tab on the left bar will present you a lot of examples using this tool drawn.

Just have a try if you are interested. 👉 [https://littlefattie.github.io/wt-huatu-editor/](https://littlefattie.github.io/wt-huatu-editor/)
